# Tarjeta de fidelización

Proyecto web del sistema de fidelización del bar: registro de clientes, tarjeta en Apple/Google Wallet y sellado de consumiciones.

## Desarrollo local

Requiere [Node.js](https://nodejs.org) instalado.

```bash
npm install
npm run dev
```

Abre http://localhost:3000

## Despliegue

Este proyecto se despliega automáticamente en [Vercel](https://vercel.com) cada vez que se sube un cambio a la rama `main` en GitHub.
